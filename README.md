# React Spring Boot CRUD Application

A full-stack CRUD application with a React frontend and a Spring Boot backend. The frontend manages the user interface and API requests, while the backend provides the REST endpoints and persistence layer.

## Features

- Create, read, update, and delete records
- React frontend with Material UI
- Spring Boot REST API
- Axios-based frontend requests
- Toast notifications and responsive layouts

## Project structure

- react-frontend - React client application
- springboot-backend - Spring Boot API and server application

## Run locally

Start the backend first:

~~~bash
cd springboot-backend
./mvnw spring-boot:run
~~~

Then start the frontend:

~~~bash
cd react-frontend
npm install
npm start
~~~

The frontend expects the Spring Boot API to be available locally.
